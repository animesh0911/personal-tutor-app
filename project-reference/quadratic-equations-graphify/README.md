# Quadratic Equations curriculum graph

This Graphify graph restructures the attached Class 10 chapter into a teaching sequence.

## Open the graph

Open `graph.html` in a browser. Search for a module or skill, click a node, and inspect its incoming and outgoing relationships.

## Edge meanings

- `prerequisite_for`: source knowledge or skill should be secure before the target.
- `precedes`: recommended teaching order from the chapter.
- `develops_skill`: a module teaches or practises the target skill.
- `assessed_by`: an exercise checks the target module.
- `applies_to`: a module is used in that problem family.
- `contains`: the item belongs to the overall course.

Graphify confidence tags are preserved: `EXTRACTED` is explicit in the chapter; `INFERRED` is a curriculum-design judgment grounded in the chapter's worked sequence.
