# Issue tracker

This repository currently uses local Markdown tickets under `.scratch/<feature>/issues/` because it has no Git repository or remote issue tracker.

- Current feature: `.scratch/personal-tutor-mvp/issues/`
- Ticket status and blocking edges live in each file and in the feature index.
- New implementation work should reference the stable local ticket ID, for example `CW-006`.
- If the project moves to GitHub, migrate these files to GitHub Issues while preserving IDs and dependencies; do not maintain two competing trackers.
- Pull requests are not an intake surface until a remote repository and workflow are explicitly configured.
